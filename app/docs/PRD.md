# Product Requirements Document (PRD)

## Product Name
PortfolioCheck

## Vision
Help students and junior developers understand the quality of their GitHub portfolio and identify the highest-impact improvements needed to become internship- or job-ready.

## Problem Statement
Many students build projects but do not know:

- Whether their portfolio is competitive
- What recruiters actually look for
- Which weaknesses are preventing them from standing out

## Target Users

### Primary Users
- SMK students (RPL, TKJ)
- University CS students
- Junior developers

### Secondary Users
- Mentors
- Recruiters
- Bootcamp students

## Goals

### Business Goals
- Acquire first 100 users
- Validate demand for portfolio analysis
- Create a shareable experience

### User Goals
- Get a portfolio score
- Receive actionable feedback
- Know what to improve next

## MVP Features

### Feature 1: GitHub Profile Analysis
User enters GitHub username.

System:
- Fetches repositories
- Fetches activity data
- Calculates score

### Feature 2: Portfolio Score
Display score from 0–100.

Categories:
- Repository Quality
- Activity
- Documentation
- Deployment
- Project Diversity

### Feature 3: Feedback Report
Show:
- Strengths
- Weaknesses
- Recommended actions

### Feature 4: Share Result
Generate shareable result page.

## Out of Scope

- AI review
- User authentication
- Payments
- Leaderboards
- Portfolio website crawling
- Human reviews

## Success Metrics

- 100 unique users
- 30% report completion rate
- 20% share rate
- 10+ feedback submissions

## Risks

- Users may not care about scores
- GitHub data may not reflect real skill
- Feedback quality may be insufficient
